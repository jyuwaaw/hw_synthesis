# Innovus Placement and Routing

This repository contains scripts and resources for using Cadence Innovus, a tool for physical design in VLSI, specifically for placement and routing.

## Prerequisites

- Cadence Innovus installed and properly configured.
- Access to the required design files (e.g., netlist, constraints, and technology files).

## Features

- Automated placement and routing scripts.
- Configuration templates for various design flows.
- Examples and documentation for common use cases.

## Usage

1. Clone this repository to your local machine:
    ```bash
    git clone <repository-url>
    ```
2. Navigate to the `scripts/innovus` directory:
    ```bash
    cd scripts/innovus
    ```
3. Modify the configuration files as needed for your design.
4. Run the provided scripts to initiate placement and routing:
    ```bash
    ./run_innovus.sh
    ```

## Directory Structure

- `scripts/`: Contains the main scripts for running Innovus.
- `configs/`: Configuration files for different design setups.
- `examples/`: Example designs and usage scenarios.

## Documentation

Refer to the official [Cadence Innovus Documentation](https://www.cadence.com/) for detailed information on tool usage and advanced features.
